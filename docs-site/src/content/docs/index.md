## Project Core Modules

- **Custom Data Structures**: Pure Java implementations of Dynamic Arrays, Linked Lists, Stack, Deque, Circular Queue, BST, Red-Black Tree, Min-Heap, Hash Tables, Custom Map & Set.
- **Searching & Sorting Engines**: Linear Search, Binary Search, Insertion Sort, Selection Sort, Merge Sort, and Quick Sort with benchmark counters and stability checks.
- **Graph & Network Routing**: Hospital road network optimization using Dijkstra Shortest Path, Kruskal & Prim Minimum Spanning Trees (MST).
- **Empirical Benchmarking & Testing**: 100% unit test coverage, formal loop invariant proofs, induction proofs, and empirical efficiency lab measurements.
