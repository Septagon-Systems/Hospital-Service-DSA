Benchmark Methodology & Measurement Protocol

Timing Precision: Measured using high-resolution hardware timers (System.nanoTime()) with 3 independent iterations per input scale to calculate mean latency and variance.

Memory Delta: Computed via JVM heap allocation deltas (Runtime.getRuntime().totalMemory() - Runtime.getRuntime().freeMemory()) before and after garbage collection cycles.

Scale Sizing: Sized across standard scales $N \in [100, 500, 1000, 5000, 10000, 20000]$ to empirically expose asymptotic divergences ($O(N^2)$ quadratic divergence vs $O(N \log N)$ linearithmic scalability vs $O(\log N)$ logarithmic flatness).
